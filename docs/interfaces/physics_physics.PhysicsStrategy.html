    Interface PhysicsStrategy

    Das mathematische Gehirn der Engine.

    Dieses Interface erzwingt, dass jede Physik-Implementierung (z.B. Arcade, Realistic) sowohl die Rechenlogik (Vektoren) als auch die physikalischen Regeln (Kollision) definiert.
