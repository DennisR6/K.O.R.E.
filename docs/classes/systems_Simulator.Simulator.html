    Class Simulator

    Der Simulator berechnet Spielzustände unabhängig von der Anzeige.

    Er wird genutzt, um einen Spielzug direkt nach dem Schuss komplett durchzurechnen ("Vorspulen"), damit das Ergebnis feststeht, bevor die Animation (Playback) beginnt.
